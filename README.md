## Tokenizer Assignment

This section contains my tokenizer assignment for my NLP coursework.

### Files Included
- tokenizer_shell.py — main Python script containing all tokenizer functions.
- sample_text.txt — text file used as input for tokenization.

### How to Run
1. Open the project in PyCharm.
2. Make sure sample_text.txt is in the same folder as tokenizer_shell.py.
3. Run the script.
4. The console will display:
   - Whitespace tokenizer results
   - Regex tokenizer results
   - Comparison of both tokenizers
